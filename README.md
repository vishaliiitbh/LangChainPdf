Overview
This project demonstrates how to create a document-based question-answering system using LangChain, Pinecone, and OpenAI. It processes PDF files, generates embeddings, stores them in Pinecone, and uses OpenAI for answering queries based on the documents.

Features
Load and process PDF files.
Split documents into chunks.
Generate embeddings using OpenAI.
Store embeddings in Pinecone.
Retrieve answers using OpenAI's language model.
